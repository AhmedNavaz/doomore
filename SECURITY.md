# Security and privacy

Doomore reads the camera, optionally the microphone, and system idle counters, all on your Mac. It saves and uploads nothing and uses no network APIs.

If you find a vulnerability or a privacy leak (anything that stores or sends frames, audio, keystrokes or app names), please report it privately through the repository's **Security → Report a vulnerability** page rather than a public issue. Expect a reply within about a week.

Only the latest commit on `main` is supported.
